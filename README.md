# 오타탈자 제보 작성기

오탈자 제보 메일의 제목, 본문과 표를 작성해 Gmail에 바로 붙여 넣을 수 있는 웹 도구입니다.
서버나 데이터베이스를 사용하지 않으며, 기본 사용자 정보만 브라우저 로컬스토리지에 저장합니다.

## 주요 기능

- 사용자 정보 기반 메일 제목·본문 생성
- 텍스트 서식과 오탈자 유형별 추천 문구
- Gmail 호환 HTML 표 및 일반 텍스트 복사
- 열람 플랫폼·기간 입력과 키보드 중심의 표 편집

## 개발 환경

- Vite
- React
- TypeScript
- Tailwind CSS
- Vitest

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

테스트, 린트와 프로덕션 빌드를 한 번에 검사합니다.

```bash
npm run check
```
