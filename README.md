# 오타탈자 제보 작성기

오탈자 제보 메일의 제목, 본문, 표를 작성하고 Gmail에 붙여 넣기 좋은 형태로 복사하는
클라이언트 전용 웹 앱입니다. 서버나 데이터베이스를 사용하지 않습니다.

## 주요 기능

- 사용자 정보로 메일 제목과 기본 본문 자동 생성
- 제목, 본문, 표를 각각 복사
- 표 셀의 일반 텍스트 붙여넣기와 간단한 글자 서식
- 단일/기간 열람 일자와 직접 입력
- 마지막 회색 행을 통한 행 추가
- 사용자 입력란만 브라우저 로컬스토리지에 저장

## 로컬 실행

Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run dev
```

품질 검사를 한 번에 실행하려면 다음 명령을 사용합니다.

```bash
npm run check
```

## GitHub 및 Vercel 배포

1. GitHub에 새 저장소를 만들고 이 프로젝트를 푸시합니다.
2. Vercel에서 **Add New → Project**를 누르고 GitHub 저장소를 가져옵니다.
3. Framework Preset이 `Vite`, Build Command가 `npm run build`, Output Directory가
   `dist`인지 확인합니다.
4. Deploy를 누릅니다. 이후 `main` 브랜치 푸시는 운영 배포, 풀 리퀘스트는 미리보기
   배포로 연결됩니다.

환경변수와 별도 `vercel.json`은 필요하지 않습니다.

## Gmail 붙여넣기 확인

배포 후 Gmail 새 메일에서 아래 항목을 확인합니다.

- 제목 복사 시 겹낫표와 한글이 유지되는가
- 본문 복사 시 문단, 줄바꿈, 굵게, 밑줄, 형광펜이 유지되는가
- 표 복사 시 테두리, 하늘색 헤더, 열 너비가 유지되는가
- 여러 줄 셀과 열람 기간이 읽기 좋게 표시되는가
- 브라우저를 새로 열었을 때 사용자 입력만 복원되고 표는 비어 있는가

일부 브라우저는 클립보드 접근에 HTTPS가 필요합니다. Vercel 배포 주소는 HTTPS를
기본 제공하며, 로컬 개발 주소(`localhost`)도 안전한 컨텍스트로 취급됩니다.
